# ИИС v3 — шаблон лаборатории агентов Claude Code

Это набор файлов, чтобы один человек мог вести несколько проектов с командой агентов Claude Code и не упираться в недельный лимит раньше времени. Внутри четыре роли, протокол связи между ними, «ворота» перед новым проектом и хук, который не даёт главной сессии раздуваться.

Шаблон вырос из личной лаборатории. В нём собраны правила, на которых мы обожглись, без привязки к конкретным проектам.

## Зачем

Агенты пишут код быстро, а время и лимит уходят на другое:

- **Длинный контекст.** Каждый ход главной сессии заново перечитывает всю историю. Ход при контексте 600 тыс. токенов у нас стоил в 4–6 раз дороже, чем при 100 тыс. Это главная статья расхода.
- **Сессии будят друг друга.** Около 30 % недельного расхода ушло на ходы, которые запустило сообщение от другой сессии, часто это было «принято» или промежуточный статус.
- **Кэш остывает после пауз.** После паузы контекст пересобирается по полной цене, у нас это около 25 %.
- **Проект, который нельзя довести.** Самая дорогая ошибка — неделя работы над тем, что в итоге человек доделал руками. От неё — ворота.

Чего мы ждали, но не подтвердилось: простые роли на дешёвой модели почти ничего не экономят, они и так стоят копейки. Sonnet дешевле Opus примерно на 25 %, а не в разы.

## Что внутри

| Файл | Что это |
|---|---|
| `install.sh` | установка: каталоги, ящики, роли, скрипты |
| `протокол.md` | как роли ставят задачи, сдают работу и кого когда зовут |
| `ворота.md` | пять вопросов перед новым проектом и бланк |
| `.claude/agents/` | четыре роли: разработчик, ревьюер, исследователь, чекер |
| `скрипты/запись.sh` | запись в ящик адресата с настоящим временем и коммитом |
| `скрипты/сдать.sh` | сдача работы проверяющему с хешем и выводом проверки |
| `скрипты/хук-потолок.py` | напоминание главной сессии очиститься при контексте больше 200 тыс. |

## Установка

Нужны git, python3 3.8+, bash и Claude Code. Проверено на macOS, на Linux должно работать, но мы не проверяли.

```bash
git clone https://github.com/firma-dev/iis-v3.git
cd iis-v3
bash install.sh --сухой
```

`--сухой` ничего не пишет и только показывает, что будет сделано. Если всё устраивает, запусти без него:

```bash
bash install.sh
```

По умолчанию лаборатория ставится в `~/lab`. Флаги:

- `--корень DIR` — другой каталог лаборатории (или переменная `LAB_ROOT`);
- `--роли a,b,c` — свой набор ролей;
- `--проект DIR` — агенты видны только в этом проекте (`DIR/.claude/agents`);
- `--глобально` — агенты видны везде (`~/.claude/agents`);
- без флага — агенты лежат в корне лаборатории, и Claude Code запускается из него;
- `--перезаписать` — заменить уже установленные файлы.

Файл настроек Claude Code скрипт не трогает. В конце он печатает кусок JSON для хука, его вставляешь сам (см. «Хук-потолок»).

После установки дай главной сессии прочитать `~/lab/связь/протокол.md` и `~/lab/ворота.md`. Дальше она сама зовёт роли.

## Как это работает

Главная сессия Claude Code — это **ведущий**. Он говорит с тобой, ставит задачи, зовёт роли и принимает результат. Роли — субагенты, они живут внутри хода ведущего:

- **разработчик** — делает задачу в своей ветке и рабочей копии, коммитит, сдаёт;
- **чекер** — независимо выполняет проверку «готово» из задачи, как выполнил бы заказчик;
- **ревьюер** — враждебно читает diff и воспроизводит заявленное настоящим вводом;
- **исследователь** — считает по данным, сверяет документы с кодом, ставит эксперименты; код продукта не пишет.

Главные правила протокола:

1. **Задача из четырёх частей:** цель, результат, чем, границы — плюс проверка «готово», которую можно выполнить и увидеть красное или зелёное.
2. **Автор не проверяет себя.** Работу разработчика принимает чекер, отчёт исследователя — ревьюер.
3. **Готово = коммит плюс запись в ящике проверяющего.** «Готово» без улики (коммит, команда и вывод, `файл:строка`) не считается.
4. **Всё в файлах.** У каждого свой ящик `связь/ящики/<кто>.md`. Статусы и «принято» пишутся туда, отдельным сообщением никого не будят.
5. **Субагент работает кусками до 150 тыс. токенов.** Не влезает — коммит и передача, продолжение новым вызовом.
6. **Ждать в фоне, а не через `sleep`.**
7. **Наружу (push, публикация, деньги, лицензии) — только слово владельца.**

Подробно — в `протокол.md`.

## Хук-потолок

Самая весомая мера. Когда контекст главной сессии больше 200 тыс. токенов, хук перед твоей репликой добавляет в ход строку «пиши передачу и очищайся». Сессия записывает передачу в `связь/передачи/`, ты очищаешь её (`/clear`), и новая сессия начинает с передачи, а не с 600 тыс. истории.

Подключение: кусок JSON, который напечатал `install.sh`, вставь в `~/.claude/settings.json` (для всех проектов) или в `<проект>/.claude/settings.json`. Если там уже есть ключ `"hooks"`, слей вручную.

```json
{
  "hooks": {
    "UserPromptSubmit": [
      { "hooks": [ { "type": "command", "command": "python3 -I '/путь/к/lab/инструменты/хук-потолок.py'" } ] }
    ]
  }
}
```

Проверка: `python3 -I ~/lab/инструменты/хук-потолок.py --проверка`.

Настройки:
- `LAB_CEILING` — порог в токенах, по умолчанию 200000;
- `LAB_ROOT` — корень лаборатории.

Если хук сломается, ход он не ломает: при любой ошибке просто молчит. Строка запаздывает на один ход, потому что хук считает по последнему ответу модели.

## Ворота

Перед новым проектом ведущий вместе с тобой письменно отвечает на пять вопросов:

1. **Итог** — что будет сделано и как узнать, что сделано.
2. **Правда** — по какому числу или факту судим об успехе и откуда оно.
3. **Проверка** — кто и как измеряет, не автор.
4. **Инструмент или руки** — строить программу стоит, только если работа повторится.
5. **Пилот и стоп** — сначала один кусок до финального качества. Если правок больше, чем сделано, остановиться.

Бланк — в `ворота.md`. Без заполненного бланка роли возвращают вопрос «где ворота?» и не начинают. «Не берём» или «берём только часть» — нормальный исход ворот.

## Часто спрашивают

**Сессия отказалась выполнять команду или сработал хук.** Не обходи другой командой. Переформулируй задачу так, чтобы запретного действия не было, или реши сам.

**Как продолжить после очистки?** Новая сессия первым делом читает свежую передачу в `связь/передачи/` и свой ящик.

**Время в записях не моё.** По умолчанию UTC. Свой пояс — переменная `LAB_TZ`, например `export LAB_TZ=Europe/Berlin` в профиле оболочки или `"env": {"LAB_TZ": "Europe/Berlin"}` в настройках Claude Code.

**Как сменить модель роли?** Строка `model:` в `.claude/agents/<роль>.md`: `sonnet`, `opus` или `haiku`. У ревьюера строки нет, он работает на модели главной сессии.

**Как удалить?** Удали каталог лаборатории, агентов из того места, куда их поставил, и блок хука из настроек.
